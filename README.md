## 1. 這是什麼系統

這是一個「**門市地圖查詢網頁**」。使用者打開網頁後，畫面左邊是門市清單，右邊是 Google 地圖，可以用**搜尋、篩選地區、篩選商品陳列**的方式，快速找到離自己最近、或有特定商品展示的門市，並且一鍵導航過去。

整個網站只有 4 個檔案，沒有資料庫、也不用架設伺服器：

| 檔案 | 作用 |
|---|---|
| `index.html` | 網頁的骨架（畫面上有哪些區塊） |
| `style.css` | 網頁的外觀（顏色、排版） |
| `stores.js` | **所有分店資料**，也就是您平常唯一需要修改的檔案 |
| `app.js` | 網頁的運作邏輯（搜尋、篩選、地圖怎麼動），一般不需要修改 |

## 2. 系統有哪些功能

- **搜尋框**：輸入門市名稱或地址關鍵字，清單會即時篩出符合的門市。
- **篩選條件**（點「篩選條件」按鈕展開）：
  - 依「地區」篩選（台北、新北、桃園、新竹、台中、嘉義、台南、高雄）
  - 只看「有電動床陳列」的門市
  - 只看「有防褥瘡床墊陳列」的門市
- **符合條件的篩選標籤**：目前套用中的搜尋字/篩選條件會顯示成一顆一顆的小標籤，點一下就能單獨取消該條件。
- **門市清單卡片**：每張卡片顯示店名、地址，點「更多資訊」可以展開看電話、營業時間、備註，還有「🚗 如何前往」按鈕（點下去會直接開 Google 地圖幫忙導航）。
- **點選門市自動置中地圖**：在清單上點一間門市，右邊地圖會自動移動並放大到該門市位置，同時彈出該門市的小視窗（店名、地址、電話）。只點「更多資訊」展開內容時，地圖不會移動。
- **地圖標記點**：地圖上每個點代表一間門市，點一下會彈出小視窗顯示店名、地址、電話。
- **手機也能用**：畫面在手機上會自動調整成上下排列（上面清單、下面地圖），不用另外做手機版。

## 3. 如何修改分店資訊

所有分店資料都寫在 [`stores.js`](stores.js) 這個檔案裡。用 VS Code 打開它，會看到一長串「一間店一組資料」的內容，長得像這樣：

```js
{
    name: "IMAGER-37 台北旗艦店",
    address: "台北市中山區松江路68號1樓",
    phone: "02-25810037",
    hours: "週一至週二、週四至週日 10:30~19:30（週三公休）",
    note: "電動床 / 防褥瘡床墊陳列",
    lat: 25.0507,
    lng: 121.5324
},
```

每一欄位的意思：

| 欄位 | 意思 | 說明 |
|---|---|---|
| `name` | 店名 | 會顯示在清單標題和地圖標記上 |
| `address` | 地址 | 會顯示在清單上，**也會被地區篩選拿來判斷「這間店是不是台北/新北…」**，所以地址裡一定要包含正確的縣市名稱 |
| `phone` | 電話 | 沒有的話可以留空字串 `""` |
| `hours` | 營業時間 | 純文字，怎麼寫都可以，會直接顯示出來 |
| `note` | 備註 | 如果這間店有「電動床」或「防褥瘡」商品陳列，**文字裡要包含「電動床」或「防褥瘡」這幾個字**，篩選功能才抓得到，例如打「電動床陳列」或「防褥瘡床墊」都可以 |
| `lat` / `lng` | 緯度 / 經度 | 決定這間店在地圖上的位置（見下方教學） |

### 3-1　修改現有門市資料

直接把對應欄位的文字改掉、存檔即可，例如要改電話，就把 `phone: "02-25810037"` 裡雙引號中間的號碼改成新的。

### 3-2　新增一間門市

1. 找一間現有門市當「範本」，把整組 `{ ... }` 連同前後的大括號一起複製一份。
2. 貼到最後一間門市的**後面**（貼在最後一個 `]` 之前）。
3. 貼上去的**前一間**門市，結尾記得要有逗號 `,`（分隔用），例如：

```js
  {
    name: "舊門市",
    ...
  },        // ← 這裡一定要有逗號
  {
    name: "新門市",     // ← 新增的這一整組
    address: "...",
    phone: "...",
    hours: "...",
    note: "...",
    lat: 24.1234,
    lng: 120.5678
  }
];              // ← 最後一個結尾，這裡是陣列的結束
```

4. 把新門市的 `name`、`address`、`phone`、`hours`、`note`、`lat`、`lng` 改成正確資料。

### 3-3　刪除一間門市

把整組 `{ ... }`（含前後大括號）刪掉，記得檢查**前一間店結尾的逗號**還在不在（規則跟上面新增時相反，多一個逗號或少一個逗號都會讓網頁壞掉，詳見第 7 節）。

### 3-4　怎麼取得經緯度（`lat` / `lng`）

1. 打開 [Google 地圖網頁版](https://www.google.com/maps)。
2. 搜尋該門市地址，找到正確地點。
3. 在地圖上該地點的位置**點右鍵**，選單裡第一個項目通常就是一串數字（例如 `25.0507, 121.5324`），點一下會自動複製。
4. 把這串數字前半段填到 `lat`、後半段填到 `lng`（中間逗號前是 `lat`，逗號後是 `lng`）。

## 4. 如何在自己電腦上先預覽（本機網址）

改完 `stores.js` 之後，不需要上傳就可以先自己看看改得對不對：

1. 用檔案總管找到專案資料夾（`google_map_test`）。
2. **直接用滑鼠雙擊 `index.html` 這個檔案**。
3. 它會自動用您電腦的瀏覽器（例如 Chrome）打開，網址列會顯示類似：

   ```
   file:///C:/Projects/google_map/google_map_test/index.html
   ```

   這個 `file:///...` 開頭的網址就是「本機網址」，只有在您自己的電腦上看得到，別人看不到，也還沒有真的發布到網路上。這一步是用來**確認修改沒有打錯字、地圖位置正確**，滿意之後再進行下一步發布。

## 5. 如何把修改發布到網路上（部署）

這個專案已經設定好「**只要把修改內容上傳到 GitHub，網站就會自動更新**」，不需要額外架站或按其他發布按鈕。上傳的動作在 VS Code 裡用滑鼠點一點就能完成，步驟如下：

1. 在 VS Code 左側工具列，點選「**原始檔控制**」圖示（一個像樹枝分岔的圖示，快速鍵 `Ctrl+Shift+G`）。
2. 會看到「變更」清單，列出您剛剛修改過的檔案（例如 `stores.js`）。
3. 滑鼠移到檔案名稱右邊，點一下「**+**」號，把它加入這次要上傳的內容（這個動作叫「暫存」）。
4. 在最上面的訊息欄位，簡單打一句話說明這次改了什麼（例如：`更新台北旗艦店電話`）。
5. 點上面的「**✓ 確認 (Commit)**」按鈕，完成「記錄這次修改」。
6. 點左下角（或視窗下方狀態列）「**同步變更 / Sync Changes**」的雲朵/箭頭圖示，把修改**真正上傳**到 GitHub。

> 可以把「暫存」想成裝箱、「確認 Commit」想成貼上標籤寫「這箱裝什麼」、「同步 Sync」想成把箱子寄出去。寄出去之後，網站大約 **1～2 分鐘內**就會自動更新成最新內容，不需要再做任何事。

## 7. 常見問題 / 小提醒

- **改完之後打開網頁整個空白 / 地圖不見了**
  幾乎都是 `stores.js` 裡的**逗號 `,`** 或**大括號 `{ }`**、**中括號 `[ ]`** 沒有配對好造成的。請對照第 3 節的格式，檢查每一間店的資料後面（除了最後一間）是不是都有逗號、括號有沒有少打或多打。

- **文字裡的引號**
  請只在 VS Code 裡編輯這個檔案，不要從 Word、LINE、備忘錄複製文字貼進去，因為那些工具打出來的引號 `“ ”` 跟程式需要的引號 `" "` 長得像但不同，貼進去會讓網頁壞掉。

- **地區篩選找不到新加的門市**
  請確認 `address` 欄位裡有正確包含縣市名稱（例如「台中市…」），篩選功能是用地址裡的文字去比對的。

- **「電動床 / 防褥瘡床墊」篩選找不到門市**
  請確認 `note` 欄位文字裡確實包含「電動床」或「防褥瘡」這幾個字。

- **地圖上的 Google 地圖功能整個沒反應（不只是資料問題）**
  這可能跟網站使用的 Google Maps 授權金鑰有關，屬於工程層級的設定，請聯絡系統開發人員協助處理，不需要自己嘗試修改 `index.html`。

- **上傳（同步）之後，網址還沒更新**
  請稍等 1～2 分鐘再重新整理瀏覽器頁面（可以按 `Ctrl+F5` 強制重新整理，避免瀏覽器顯示舊的快取畫面）。
